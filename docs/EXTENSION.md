# Historical browser integrations

The userscript and Chromium/Firefox extensions were retired from the active product in 0.3.0. Wipeditt now ships as a desktop application with an isolated native Reddit website session. Follow the [desktop guide](USER-GUIDE.md).

Historical source and packages remain at [v0.2.0](https://github.com/rafelolv/Wipeditt/tree/v0.2.0). That OAuth integration required a registered Reddit application; those setup instructions do not apply to the desktop connector. Old versions are not the maintained distribution.
