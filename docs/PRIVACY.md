# Privacy and data lifecycle — 0.2.0

Requests go directly to www.reddit.com for installed-app OAuth exchange and oauth.reddit.com for documented account/history/content API calls. No proprietary backend, proxy, analytics, telemetry, tracking, remote configuration, runtime CDN or external fonts exist. No requests occur until an explicit connection or account operation. README badges are external images, not runtime dependencies.

The user signs in on Reddit. Wipeditt never asks for Reddit passwords/client secrets or extracts website cookies/tokens. Public Client ID is the only persistent connection setting (`localStorage: wipeditt.clientId`). Authorization codes are transient, removed from callback URLs and delivered to a matching state/window or same-origin channel. Access tokens stay in private memory, expire after at most one hour, and are cleared by disconnect/panel close/reload. No refresh token is retained. There is no encrypted credential vault because tokens are not persisted.

Userscript requests are anonymous/cookie-free through the manager. Extension transport is packaged, sender-validated, path-restricted and uses credentials:omit, no-referrer and redirect rejection. There are no background mutations, credentials in reports or logs, pasted-token inputs or unrelated destinations. OAuth/network responses necessarily contain account/content data in memory; do not describe the runtime as network-free.

Account and preview content are held in memory. Closing the panel invalidates/clears the real-account preview and token. Reloading/closing the tab clears runtime memory. Verified replacement updates the retained preview; original text is not copied to reports/checkpoints/activity. Garbage collection timing is browser-controlled, not secure memory erasure.

`sessionStorage: wipeditt.checkpoint.v1` holds `{ id, state }` records, a simulation flag and 24-hour expiry, enforced on next read. Sessions can be restored by a browser. Same-origin scripts can access this unencrypted storage. Clear local checkpoint removes it. No account identifier, text, replacement, subreddit, filter or credential is persisted there. Storage denial leaves the app usable without saved recovery state.

Pending/editing/waiting checkpoint states load as uncertain; they never resume automatically. Fresh scan/review/current-state verification are required. Reports contain version/time, operation, simulation flag, elapsed time, safe filter flags, counts, issue IDs/categories and pacing statistics. IDs can identify content; review reports before sharing. Export uses a local Blob download. Activity is bounded to 30 status/ID entries.

Privacy mode is visual masking, not encryption. Ownership checks always use real account data. Demo mode disconnects real authorization before creating synthetic records. Reddit's [retention rules](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki) remain applicable. Replacing visible text cannot guarantee removal from Reddit records, caches, archives or third-party copies.
