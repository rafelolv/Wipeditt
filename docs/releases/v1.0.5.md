# Wipeditt v1.0.5

App animations now remain active regardless of the system reduced-motion preference. This includes update-check and progress spinners, button and row hover effects, transitions, dialogs and panel entrances. No additional setting is required.

Dependency version metadata in the lockfile now matches its existing tarballs and integrity hashes; no dependencies were upgraded.

The Electron update-check fixture verifies that the spinner remains animated with both normal and reduced-motion media preferences. Source checks, unit tests and the isolated Electron suites validate the change; automated tests never modify real Reddit content.

GPL-3.0-only. Official Linux x64 and Windows x64 packages, corresponding source ZIP and SHA256SUMS.
