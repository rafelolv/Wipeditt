# Wipeditt v1.1.2

Community selection now selects only that community and clears the previous selection. Choosing an already selected community no longer deselects it while leaving unrelated items selected. Batch selection uses one pass, and progress starts with the selected count. Activity starts fresh for each import, scan and operation.

CSV imports exclude real deletions previously verified by Wipeditt for 24 hours, including across restarts. This history stores only expiring content IDs alongside minimized checkpoints. Simulation, failed, skipped and uncertain operations never become deletion evidence. A fresh live listing overrides remembered deletion IDs; disconnect or Clear checkpoint clears this history. Export rows containing deleted/removed markers remain excluded. Exports are snapshots: an item deleted after export still needs an initial live check unless Wipeditt has verified its deletion. Unselected originals are never opened during execution.

A missing original before submission is skipped with ORIGINAL_UNAVAILABLE and a readable reason; it is not counted as a verified deletion. Missing or ambiguous evidence after submission remains uncertain and is never automatically replayed. Other skipped items now show their capability/ownership reason. Owned comments with native edit controls remain editable on archived/locked threads; all live ownership and permission checks still apply.

Stalled login navigation can be canceled from the sidebar. Navigation cancellation settles promptly even if Chromium's load promise does not. Failed/canceled account verification restores the Reddit view and releases the controls instead of leaving permanent verification state. Automatic verification waits for the settled page before hiding it. Packaged Linux dependency notices load from the distributed notices file.

Validation includes the 3,887-row/47-selected regression, unavailable preflight versus submitted uncertainty, expiring deletion history with real debounced desktop storage, canceled/failed login recovery and archived/locked DOM layouts. Electron uses an isolated profile and synthetic HTTPS Reddit pages. Automated tests never modify real Reddit content. Integrated updates retain explicit download/install clicks; an installed Windows/AppImage upgrade still needs maintainer confirmation.

GPL-3.0-only. Official Windows x64 and Linux x64 binaries, corresponding source ZIP and SHA256SUMS.
