# Wipeditt v0.4.1 — Automatic verification and reliable ownership

Wipeditt 0.4.1 fixes the two problems reported after 0.4.0: login now verifies the account automatically, and own comments no longer become unselectable when Reddit omits part of its author metadata.

## What changed

- **Automatic account verification.** After the initial Reddit login leaves the credential screens, Wipeditt verifies the account and closes the embedded browser without requiring a **Verify account** click. The button remains as a manual fallback.
- **Reliable ownership detection.** Classic listings expose ownership through a profile link, `data-author` or the visible author link. Wipeditt now reads all three, normalizes prefixes and falls back when a layout omits one, instead of marking most own comments as `Ownership could not be verified`.
- **Same fail-closed behavior.** Foreign or ambiguous authors still cannot be selected. Every write continues to reload the original, verify the signed-in account and author, and confirm the saved text after a fresh page load.

## Safety is unchanged

The app still does not extract cookies, passwords or tokens, does not read a system browser profile and does not replay private endpoints. Live mode replaces only editable comment and text-post bodies. Deletion remains disabled for real accounts; sample mode stays clearly labeled.

## Validation

- 45 deterministic unit tests pass.
- The Electron fixture suite passes, including automatic verification after login and scans where an item has only a profile link or only `data-author`.
- Earlier manual checks confirmed real sign-in, account verification and history reading in 0.3.1. The 0.4.1 fixes are validated with synthetic fixtures; they have not been revalidated against a real account.
- **Real-account editing has not been validated. Live deletion remains disabled.**

## Distribution

Linux x64 AppImage/deb, Windows x64 installer, macOS arm64/x64 disk images, source archive and `SHA256SUMS` are built natively by CI. Packages are unsigned and macOS builds are not notarized. This remains a technical prerelease. Replacing text can be permanent, and external copies cannot be removed.
