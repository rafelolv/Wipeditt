# Wipeditt v1.0.0

Anonymize, Delete and Anonymize & Delete are enabled in production. Native ownership/account checks, explicit confirmation, independent verification, serial scheduling and uncertain-write protection remain in force. Combined mode never deletes after an unverified edit.

Results now use visible green success, red failure, amber partial/uncertain/stopped outcomes and blue progress, with text labels and stage counts. Update checking is a visible sidebar control; checks remain optional and installation remains manual. Sample-data UI, IPC and its dataset are removed from the production bundle; synthetic adapters/fixtures remain available to tests.

The default replacement reads: “This comment was anonymized using Wipeditt, a free and open-source tool.” followed by a Reddit Markdown link named Wipeditt. It remains editable before confirmation.

License: GPL-3.0-only, retaining Rafael attribution and dependency notices. Platforms: Linux x64 and Windows x64 only. Assets include AppImage, DEB, Windows installer, corresponding source ZIP and SHA256SUMS. Packages are unsigned.

Evidence: the maintainer independently confirmed a real RC3 combined-comment operation with anonymization and deletion verified, then approved production release on November 8, 2026 while deferring finer tests. Direct/post/interruption cases are covered by synthetic fixtures; the detailed live matrix remains incomplete and no live Windows mutation is claimed. See docs/DELETION-VALIDATION.md. Automated tests never modify real Reddit content. No mode guarantees removal of external copies.
