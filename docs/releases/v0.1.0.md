Wipeditt 0.1.0 is a **technical preview with blocked live Reddit integration**. It cannot read or modify a real Reddit account. Select **Try synthetic data** to exercise the complete local workflow.

## Changes

- Add comment/text-post discovery, filters, review and individual/subreddit selection.
- Add exact custom replacement previews and explicit, expiring confirmation.
- Add anonymize, delete and verified combined workflows using synthetic data only.
- Add serial request pacing, bounded cooldowns, pause/resume and Stop.
- Add uncertain outcomes, minimal checkpoints and private local reports.
- Add dark/light themes, privacy masking and responsive Shadow DOM isolation.
- Package the same runtime as a userscript and unsigned Chromium/Firefox extensions.
- Apply Rafael (rafaelolv)'s Wipeditt Proprietary License to original material.

## Validation

Deterministic mocked engine/scheduler/privacy tests and isolated Chromium browser tests. Build checks validate version alignment, licenses, byte-identical extension runtimes, ZIPs and SHA256SUMS. Browser tests load the actual unpacked Chromium content script using a temporary loopback-only manifest. No real Reddit account, edit or deletion was tested.

## Limitations

Reddit approval, a verified public-client OAuth flow and live transport are not implemented. Live anonymization/deletion are unavailable. Official export import, Firefox runtime validation, userscript-manager verification and signed store packages remain unfinished. Account listings cannot guarantee complete history; edits cannot guarantee removal from archives/caches.

## Install

Userscript: install the attached `wipeditt.user.js` using Tampermonkey or Violentmonkey; manager/browser combinations are not independently tested. For Chromium, unzip the package and Load unpacked in Developer mode. For Firefox, load the unzipped manifest through about:debugging as a temporary add-on. Neither ZIP is signed or store-published. Compare downloads against the attached SHA256SUMS. See the repository README and user guide before use.
