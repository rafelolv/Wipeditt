# Wipeditt v1.0.0-rc.3 — Verify deleted leaf comments

This candidate fixes verification when Reddit removes a leaf comment without leaving a deleted placeholder. Success requires the completed native delete, the exact focused original (context=0), the matching available parent post, Reddit's explicit empty-thread marker and two consecutive fresh reads. Bare disappearance, history absence, network failures and unrecognized layouts remain uncertain. The in-memory proof expires after five minutes, stays bound to the item/account/permalink and never authorizes a write or automatic replay. Existing placeholder verification remains available for comments and posts.

Uncertain outcomes now display “Verification incomplete” and an inspection instruction instead of a success checkmark. Separate anonymization/deletion stage results remain intact.

Validation: 69 unit tests; baseline and native deletion Electron fixtures cover direct/combined empty leaf threads, missing receipt/marker/parent, wrong targets and uncertain outcomes. All automated content is synthetic. Independent live validation remains incomplete: RC2's maintainer-reported deletion left an empty original but was uncertain in the app. Production deletion stays gated; stable v1 remains blocked pending the manual checklist.

GPL-3.0-only, Rafael attribution and dependency notices remain. Official platforms: Linux x64 and Windows x64. No macOS or ARM assets.
