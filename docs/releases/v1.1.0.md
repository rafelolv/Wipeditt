# Wipeditt v1.1.0

Windows x64 and Linux AppImage users can download a verified update inside Wipeditt, then choose Install and restart. GitHub Releases remains the only update service. Debian packages retain View release. Install this version manually once; older Wipeditt versions do not contain the integrated updater.

Checking automatically remains optional. Downloads require a click and installation requires a separate click while Reddit work is idle. Closing the app does not install a pending update. The updater uses the official release asset's SHA256 digest, checks bytes again before installation, restricts HTTPS download origins and never sends Reddit data, cookies, credentials or a staged-rollout identifier. Unknown metadata and unsupported packages fall back to the official release page.

The footer now has a Made by Rafael link to the GitHub project. License & source retains the GPL and warranty text and includes runtime dependency notices.

Validation covers the updater state machine, corruption, mismatched origins/versions/packages, busy-operation gates and a real electron-updater download through synthetic HTTPS. The OS installer handoff is stubbed in automated tests; an installed Windows/AppImage upgrade between published versions still requires maintainer confirmation. Existing Reddit edit/delete fixtures also run. No real Reddit content or OS installation is changed by automated tests.

GPL-3.0-only. Official Linux x64 and Windows x64 binaries, corresponding source ZIP and SHA256SUMS. See docs/UPDATES.md for implementation and validation limits.
