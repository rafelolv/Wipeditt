# Wipeditt v1.2.2

Fix a path that could keep moving the Waiting for Reddit deadline instead of letting its countdown finish. The previous response listener accepted rate metadata from every Reddit resource, including background requests. A repeated relative reset duration could be added to the current time again and again.

The main process now observes uncached responses belonging to its Reddit view's navigations or active native write requests. Images, scripts, subframes and unrelated background XHR no longer impose scheduling deadlines. Redirect responses remain covered. HTTP Date identifies a quota window and anchors its local deadline once, preserving client clock-skew tolerance; response Age discounts stale metadata. Repeated or older copies of that window cannot renew it. Fresh longer windows and explicit Retry-After/body cooldowns still impose their full wait. There is no arbitrary shortened cooldown or skip-wait button.

The existing wait line now identifies a Reddit cooldown and automatic continuation. Elapsed operation time advances during scheduler wait updates. Stop interrupts waiting without dispatching another request, and restarting an operation preserves any unexpired server cooldown. No buttons or manual prechecking steps are added. Ambiguous writes are never automatically replayed; uncertain originals still require review.

Validation includes replaying a 600-second quota header throughout the entire simulated window, clock skew, genuine longer limits, Age, cached/background traffic, native-write 429 responses and Stop without dispatch. An isolated Electron HTTPS fixture receives real webRequest events, injects image/XHR 429 responses during a foreground cooldown, checks decreasing time, tests Stop, preserves the deadline on restart and verifies automatic continuation after expiry. Its clock is advanced only in the test process; no real Reddit writes are submitted. Existing native edit/delete fixtures remain required on Linux x64 and Windows x64.

Implementation references: [Electron webRequest response/cache metadata](https://www.electronjs.org/docs/latest/api/web-request/), [Reddit response-header semantics](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki), and [HTTP Retry-After](https://www.rfc-editor.org/rfc/rfc9110.html#section-10.2.3). Website limits need not match the Data API request budget; this change does not assume or raise that budget. The reported live incident is consistent with the reproduced path, but its actual original response headers were not collected.

GPL-3.0-only. Official Linux x64 and Windows x64 packages, corresponding source ZIP and SHA256SUMS.
