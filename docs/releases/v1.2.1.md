# Wipeditt v1.2.1

Restore the CSV workflow from v1.1.3. Import prepares the matching rows for selection and review; there is no separate Check next step. Eligible rows are selected by default again. Users can adjust selection before explicitly confirming anonymization, deletion or the combined mode.

Remove the manual read-only batch interface, its extra eligibility gate, lightweight listing mode and found-candidate history introduced in v1.2.0. Preserve the prior optimizations: deleted/removed export markers are excluded, known deletions are remembered for 24 hours and unavailable originals are deferred for six hours. Previously unavailable rows can still be restored unselected for explicit review. Old found-candidate entries are ignored and disappear on the next checkpoint save; no operation resumes automatically.

Live account/author preflights, serial scheduling and cooldowns, preview expiry, explicit confirmation, independently verified combined stages and protection against ambiguous write replay remain unchanged. CSV eligibility is provisional until native preflight; an unknown stale row may still need an initial focused read during the confirmed operation.

Validation restores the v1.1.3 regression suite and runs source/build checks plus isolated Electron fixtures. Production runtime and fixture sources match v1.1.3 exactly. Automated tests do not modify real Reddit content.

The higher version number allows normal in-app updates from v1.2.0. Official Windows x64 and Linux x64 packages only, with corresponding source ZIP and SHA256SUMS. GPL-3.0-only.
