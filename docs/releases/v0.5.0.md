# Wipeditt v0.5.0 — Author recovery and monochrome desktop

Own comments could become unavailable when a classic listing omitted an author link or data attribute. The connector now recognizes item-local author spans and native author-only edit controls, checks available evidence for agreement, and reads the original permalink when listing authorship remains unknown. Nested context replies no longer become separate profile-history entries. Unknown authors and known foreign content have distinct review messages.

The desktop now uses black, charcoal and white by default, flatter rows, simpler typography and one primary action per stage. Optional light appearance remains available. The welcome illustration, warm gradients and decorative cards have been removed; app artwork matches the monochrome interface.

Validation: 46 unit tests and actual Electron fixture tests cover a 65-own-comment author regression, native edit controls, missing listing metadata resolved on its original, conflicting/deleted/external authors, nested context, foreign-content rejection and the existing confirmation/edit-verification flow. Screenshots use synthetic data. The reported real-account case still needs revalidation with this version; no real content was changed by automated tests.

Live mode replaces body text only. Deletion stays disabled. Every write independently rechecks account and author on a fresh original. Linux x64 AppImage/deb, Windows x64 installer and macOS arm64/x64 disk images are unsigned; macOS builds are not notarized. Source and SHA256SUMS accompany the preview.
