# Wipeditt v0.3.0 — Unpublished desktop attempt

Wipeditt is now a desktop application. Sign in directly on Reddit in an isolated browser, verify the account, scan and review your history, then explicitly confirm body replacement. No Reddit Client ID is required for the native website connector.

The interface separates connection, review and execution. It includes per-item selection, filters, exact replacement preview, light/dark themes, privacy mode, progress, pause/stop, local reports and opt-in session memory. Original Wipeditt material remains proprietary to Rafael (rafaelolv).

Native actions use the website's own edit/save controls, recheck account and authorship before submitting, and verify the replacement after a fresh navigation. Authentication/account changes and uncertain writes stop work. No cookie extraction, copied API tokens or private endpoint fallback is implemented.

The maintainer confirmed real sign-in/account identification and a five-item history scan displaying their comments. Automated unit and Electron tests cover native edits against synthetic local pages. **Real-account editing has not been validated. Live deletion is disabled.** Listings are partial and replacement cannot erase external copies.

Distribution: Linux x64 AppImage/deb, Windows x64 installer, macOS arm64/x64 disk images, source archive and SHA256SUMS. Packages are unsigned; macOS builds are not notarized. This is a prerelease. Previous userscript/extension distributions remain historical.
