# Wipeditt v1.0.0-rc.1 — Three modes, GPLv3, Linux/Windows

This candidate implements Anonymize, Delete and Anonymize & Delete in the existing native connector and shared engine. Delete uses Reddit's own button and confirmation; a fresh original must positively confirm a deleted placeholder. Combined mode verifies replacement independently before deleting. Failed, partial and uncertain stage outcomes remain separate in reports/checkpoints; ambiguous writes are never replayed.

Local validation passed 63 unit tests and both Electron fixture suites, including comment/text/link-post deletion, combined comment/text-post success, explicit rejection, partial completion, Stop and missing-page uncertainty. No automated test used real Reddit content.

Production deletion remains gated until independent disposable-content validation is completed. Run `npm run validate:deletion` from source for explicit unpackaged testing with a separate app profile, and follow docs/DELETION-VALIDATION.md. Packaged apps cannot unlock deletion via that environment flag. Stable v1 publication is blocked while the record is incomplete.

Current Wipeditt original code, documentation and artwork are GPL-3.0-only. Rafael's copyright/attribution remain; the full license, NOTICE, matching source/build scripts and independent dependency notices accompany the distribution. Older tags retain their historical licenses.

Official platforms are now Linux x64 and Windows x64 only. macOS and ARM support/builds have been retired. Assets: Linux AppImage/deb, Windows installer, matching source ZIP and SHA256SUMS. Packages are unsigned. No automated test changed real Reddit content. Neither editing nor deletion guarantees erasure of external copies.
