# Wipeditt v1.0.6

Repeated reads of the currently loaded focused original now inspect the live DOM without spending another network interval. Reads remain serialized, recheck the exact URL inside the queue and validate the account. Body expansion returns to network pacing. Fresh preflights before writes, independent mutation verification and Reddit cooldowns remain intact. No item text is cached and no ambiguous write is replayed. Actual speed depends on Reddit and the connection.

History discovery requests up to 100 items on the initial HTML profile page and follows both classic next-button and rel=next pagination links supplied by Reddit. Wipeditt has no eight-month cutoff and does not stop at 1,000 comments, but Reddit can end its listing before an account's oldest content. The profile listing is not a complete archive.

Results now offer Import older comments and access to the existing official-export instructions. The CSV importer accepts exports without an author column and relative Reddit permalinks. Imported account labels are preview claims only: live author/account checks still govern every write. Explicit foreign authors and unsafe links are rejected. Requesting and downloading the export remains a user action; no account data is requested automatically.

Validation includes 89 unit tests, a synthetic 1,205-comment history reaching 2012, uncached same-page reads, queued navigation, account guards, author-less CSVs, relative/unsafe links and forged ownership claims without writes. Electron fixtures cover alternate pagination, export access and the native edit/delete paths. These are synthetic checks, not proof that all older live Reddit comments become available or a real-world speed benchmark.

GPL-3.0-only. Official Linux x64 and Windows x64 packages, corresponding source ZIP and SHA256SUMS.
