# Wipeditt v0.4.0 — Clearer review, older history

Wipeditt 0.4.0 refreshes the desktop app and makes it easier to review a full-looking history without losing control.

## What changed

- **New visual system.** A warm light theme and a full dark theme, a clearer three-step flow, responsive review layout, readable cards and a finished-state summary.
- **No app-imposed item cap.** Live scans follow every history page Reddit exposes. Reddit can still stop a listing early, so complete coverage remains impossible to guarantee.
- **Older comments.** Import `comments.csv` from Reddit's official data export. The file is parsed locally, filtered to the verified account and rechecked against Reddit before any write.
- **Better selection.** Ten-item review pages, whole-row and checkbox selection, select-all/clear and community selection. Selection persists across pages until it is changed.
- **More comfortable defaults.** Theme and privacy preferences persist locally; the confirmation and report flow is clearer.

## Safety is unchanged

Live mode still replaces only editable comment and text-post bodies. Every write reloads the original, verifies the account and author, and checks the saved text after a fresh navigation. Authentication or account changes stop the operation. Ambiguous writes are never replayed. Deletion remains disabled for real accounts; sample mode is clearly labeled.

Wipeditt does not extract cookies, passwords or tokens, does not read a system browser profile and does not replay private endpoints. Reddit is an independent platform; its availability, rules and rate limits still apply.

## Validation

- 44 deterministic unit tests pass.
- The Electron fixture suite passes, including isolated login, uncapped fixture pagination, review selection, import mapping, light/dark/privacy UI, text-post handling, server rejection and account changes.
- Earlier manual checks confirmed real sign-in, account verification and history reading in 0.3.1. The redesigned 0.4.0 UI, uncapped scan and import path are validated with synthetic fixtures; they have not been revalidated against a real account.
- **Real-account editing has not been validated. Live deletion remains disabled.**

## Distribution

Linux x64 AppImage/deb, Windows x64 installer, macOS arm64/x64 disk images, source archive and `SHA256SUMS` are built natively by CI. Packages are unsigned and macOS builds are not notarized. This remains a technical prerelease. Replacing text can be permanent, and external copies cannot be removed.
