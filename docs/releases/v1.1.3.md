# Wipeditt v1.1.3

Repeated CSV imports now defer originals that Reddit did not show before any write was submitted. The app remembers their IDs separately for six hours, including across restarts, and reports how many matching rows were deferred. Originals positively observed as already deleted are excluded for 24 hours, as are verified deletions performed by Wipeditt. These optimizations avoid reopening known stale export rows; an initial check is still necessary when no recent observation exists.

Review unavailable items restores deferred rows to the current review, unselected. Existing selections remain intact. Restoring rows makes no network request, submits no action, invalidates prior confirmation and does not renew the five-minute preview lifetime. Operation-mode eligibility is recalculated. Selecting restored items still requires explicit confirmation and fresh native ownership/capability checks before a write.

Unavailability is not deletion evidence and does not increase deletion verification counters. Submitted uncertain actions, permission failures and unrelated skips never become unavailable-history entries. The app never automatically retries ambiguous writes. Fresh eligible owned content clears its unavailable entry; disconnect and Clear local checkpoint clear the history. Progress updates cannot keep extending an old observation's expiry. History stores only bounded, expiring IDs/statuses alongside existing minimized checkpoints, never bodies or account identifiers.

Validation covers restart persistence, simulation isolation, expiry without renewal, observed prior deletion, exclusion without repeated item reads, explicit unselected restoration, selection preservation, changed modes, confirmation invalidation and expired previews. An isolated Electron HTTPS fixture imports a synthetic CSV, observes a missing original, reimports without navigation and restores it without writes. Existing native edit/delete fixtures remain required on Windows x64 and Linux x64. Automated tests do not modify real Reddit content.

Integrated GitHub updates remain available for Windows x64 and Linux AppImage with separate download/install clicks. Debian packages retain the manual release flow. GPL-3.0-only; official binaries include corresponding source ZIP and SHA256SUMS.
