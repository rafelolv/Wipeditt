Wipeditt 0.2.0 adds **real OAuth authentication and Reddit history/anonymization requests**, replacing 0.1.0's permanently blocked adapter. It remains a prerelease: end-to-end tests use intercepted HTTP fixtures; no real registered app/account was accessed.

## Changes

- Add guided installed-app configuration and Sign in with Reddit.
- Keep authorization tokens in memory and clear them on disconnect/panel close.
- Add official history discovery, account/ownership guards and verified replacement edits.
- Add restricted userscript networking and a packaged extension request broker without cookies.
- Respect pacing/cooldowns for authentication, reads, preflights and writes.
- Simplify the main UI to connect, choose content and review/replace.
- Move demo, detailed filters and advanced controls out of the main flow.
- Update replacement previews without fetching history again.
- Add same-origin cross-tab exclusion for live operations.

## Setup

Open www.reddit.com → Wipeditt → Connect Reddit. Create/configure an **installed app** with redirect URI exactly `https://www.reddit.com/`, enter its public Client ID, then complete Reddit consent. No password, client secret or pasted token is requested. There is no shared Wipeditt registration. Reddit may require explicit approval before creating/enabling your app; this release cannot bypass that requirement or claim approval for your use case.

## Validation and limitations

50 deterministic tests and isolated Chromium tests drive the real OAuth callback/token exchange and API scan/edit/verification paths using intercepted HTTP fixtures. The extension suite uses its unmodified manifest, actual content script and packaged broker. Build checks verify versions, licenses, parity, ZIPs and SHA256SUMS. Real Reddit registration/redirect acceptance, authentication and anonymization remain unverified. Firefox and installed userscript-manager combinations remain unverified. Live deletion/combined mode remain disabled until separately validated. Official export import and signed store packages are unfinished.

Userscript and unsigned Chromium/Firefox ZIP installation instructions are in README. Compare downloads with the attached SHA256SUMS. The source archive supports inspection; the proprietary license remains unchanged under Rafael (rafaelolv).
