# Wipeditt v0.6.0 — New version notices

The app now shows a new-version banner when a newer compatible release is available. View release opens only the official Wipeditt GitHub release page; downloads and installation remain manual.

Packaged apps check public release metadata at startup and at most every four hours while idle. Settings & tools includes Check for updates and an automatic-check opt-out. Development builds check only on request. No Reddit credentials, content or identifiers are sent. GitHub sees normal request connection metadata.

Checks compare semantic versions, include published previews for preview installations, reject draft/incomplete/wrong-platform releases and require uploaded checksums and a compatible installer. Requests have a size limit and timeout, are coalesced and throttled, and cannot redirect the release button to an arbitrary website. Failure never blocks Reddit operations.

Validation: 53 unit tests plus the Electron fixture suite, including a synthetic update notification, manual check with automatic checks disabled, no credential headers, request throttling and captured official release navigation. Install 0.6.0 manually once; versions without this feature cannot display future notices.

Linux x64 AppImage/deb, Windows x64 installer and macOS arm64/x64 disk images remain unsigned; macOS builds are not notarized. Source and SHA256SUMS accompany this technical preview. Live deletion remains disabled.
