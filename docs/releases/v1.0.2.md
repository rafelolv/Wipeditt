# Wipeditt v1.0.2

Buttons now respond to hover, press and keyboard focus with subtle motion, shading and focus rings. Inputs and history rows have smooth state transitions; dialogs, results and update notices enter with a brief fade. The black interface and semantic result colors remain.

Check for updates now has a refresh icon, hover highlight, a real-request loading spinner and completion/error icons. During a check it displays Checking…, announces its busy state and prevents duplicate clicks. Existing throttling, privacy controls and manual installation behavior are unchanged.

Reduced-motion preferences disable decorative animation, including the spinner, while retaining status text, icons and focus indicators. Electron fixtures check the pending request, disabled/busy state, reduced-motion behavior and successful completion. Automated tests use isolated synthetic sessions.

GPL-3.0-only. Linux x64 and Windows x64 only. Assets include native packages, corresponding source ZIP and SHA256SUMS.
