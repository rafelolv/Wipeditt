# Wipeditt v1.0.4

Confirmed batches continue past isolated uncertain items without replaying their writes. Combined mode never deletes an item whose anonymization was not verified. Account/permission changes, Stop, outstanding native requests and prolonged connection failures still stop the operation. Reports retain every uncertain item for manual inspection.

Native deletion now checks the fresh original even when the page widget stays stale. Completed transport failures can be reconciled by read-only verification; pending requests cannot authorize further writes. Empty-thread deletion evidence still requires a successful native receipt and two fresh focused reads. Native request observation allows 30 seconds rather than 15.

Read-only connection failures use six bounded retries with 5–30 second backoff. Failed navigations cannot be mistaken for loaded pages on retry. Preflight reads can recover before a write is dispatched. This is bounded recovery, not persistent automatic resume.

Item preflights use focused original pages rather than loading surrounding comment threads. Local identity checks remain serialized but no longer consume the network interval. Network navigation and writes retain the configured interval and stricter server cooldowns. Short routine countdowns are hidden; long waits and pause remain visible. No telemetry or more aggressive request frequency was added.

Classic account verification is hidden behind the app after sign-in; Reddit credential and second-factor pages remain visible. Neutral violet replaces informational blue, with section transitions and a working indicator that respect reduced motion. Retired sample branches, unused helpers and an obsolete ZIP script were removed.

Validation: unit tests (including a 300-item batch with one isolated uncertain edit), isolated Electron fixtures, native synthetic edit/delete cases, themes, account changes and Stop. No real Reddit account was accessed or modified by automated tests. Real intermittent Reddit/network behavior still needs maintainer confirmation.

Sources reviewed: [Reddit Data API limits](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki) apply to OAuth clients, not a published safe frequency for the website; [Electron network detection](https://www.electronjs.org/docs/latest/tutorial/online-offline-events/) warns that an online flag alone does not prove connectivity. Recovery uses actual navigation failures.

GPL-3.0-only. Official Linux x64 and Windows x64 packages, corresponding source ZIP and SHA256SUMS.
