# Wipeditt v1.0.1

Status messages no longer show a colored stripe on the left. Semantic text colors and the subtle background remain, preserving visible success, error, warning and progress states.

The change is presentational. Reddit scanning, anonymization, deletion and verification behavior are unchanged. Automated Electron inspection confirmed a zero-width left border in every status tone while retaining four distinct text colors. Required source/build checks and Linux x64 / Windows x64 release CI cover the packages.

GPL-3.0-only. Linux x64 and Windows x64 only. Assets: AppImage, DEB, Windows installer, corresponding source ZIP and SHA256SUMS.
