# Wipeditt v1.0.3

Fixes false uncertain edit results for Markdown replacements, including the default Wipeditt link. The native form's rendered text is no longer compared with raw Markdown. Editing observes request completion and verifies raw saved source on bounded fresh reads. Only reads are retried; submitted edits are never replayed automatically. Combined mode still requires verified anonymization before deletion. Genuine missing/mismatched evidence remains uncertain, with a diagnostic category and an Inspect original action.

Expired previews now have a direct Refresh results action. Imported previews use Re-import export, preserving their source. Expiration remains five minutes and cancels stale confirmations; refreshing never applies changes automatically. Previous reports remain available after a new search. Importing a comments export correctly sets the visible content type to Comments.

Theme selection now reaches the root native color scheme and dropdown options explicitly use theme colors. All result states share an aligned card with a fixed icon, consistent text/actions and separate stage metrics; unrequested stages are labeled accordingly. The result card appears before new-search controls. Short windows use a compact sidebar so the update button stays accessible. Semantic colors and reduced-motion support remain.

Validation uses unit tests and isolated Electron fixtures, including rendered Markdown, delayed edit completion, non-persisted edits without deletion, expiry/refresh without writes, report preservation and dark/light dropdown styles. Automated tests do not change real Reddit content. Previously uncertain items must be inspected rather than repeated.

GPL-3.0-only. Official packages: Linux x64 and Windows x64, corresponding source ZIP and SHA256SUMS.
