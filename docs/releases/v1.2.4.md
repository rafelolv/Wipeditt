# Wipeditt v1.2.4

This release restarts publication of the v1.2.3 fix after repeated GitHub Actions internal errors left its release attempts incomplete. Windows and Linux validations succeeded across separate attempts, but the publish job never ran. The native runtime changes remain the same.

Find older comments exposed by the ordinary classic Reddit profile without requiring a CSV import. The history URL guard previously accepted only named tabs such as `/comments/` and `/overview/`, rejecting the native `/user/name/?count=25&after=...` form reported by the maintainer. The DOM reader also required a next class or relation; it now recognizes forward `after` cursors in native pagination controls, excluding previous links and controls embedded in comments.

Comment searches continue through the Comments tab's native forward links, then automatically search the ordinary profile overview if that tab ends. The engine combines and deduplicates matches, keeps comment/post and other filters, respects an explicit item limit, and selects eligible rows using the existing review workflow. No extra buttons or manual checking steps are introduced. Additional overview pages may increase scan duration; server pacing and cooldowns remain enforced. Listings still cannot guarantee a complete archive.

Validation: Node coverage checks root URL acceptance, foreign-account/origin rejection, automatic overview continuation, duplicate elimination, older date-filter matches and item caps. An isolated Electron HTTPS fixture ends the Comments tab, then serves three profile pages including synthetic comments from 2020 and 2018, duplicate recent content and a post. It checks exact native root cursors, previous-link rejection, unchanged selection counts and zero writes during the scan. Normal fixtures also paginate using root links without `rel=next`. Existing edit/delete and cooldown recovery fixtures remain required on Linux x64 and Windows x64.

The maintainer supplied rendered page text and a native profile URL. Those excerpts establish visible content and forward controls, but do not contain their HTML attributes. An unauthenticated attempt to read the public page was blocked by Reddit, so this release's validation is synthetic; the maintainer's signed-in old-history scan remains to be confirmed. No private endpoints, credentials or real account writes were used.

GPL-3.0-only. Official Linux x64 and Windows x64 packages, corresponding source ZIP and SHA256SUMS.
