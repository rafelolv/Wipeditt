# Wipeditt v1.2.0

CSV import now starts with zero selected items. Unchecked rows cannot enter a write confirmation. Check next reads up to 100 originals without editing or deleting anything. Afterward, users explicitly select found candidates and review the operation. Imported counts and confirmation text distinguish candidates from currently verified eligibility; cached observations are labeled Previously found and are always rechecked before writes.

Read-only checking first matches export IDs against native profile pages. Lightweight listing reads avoid eager per-item source hydration during this phase. Entries already exposing the required ownership and capabilities can be checked together without opening each original. Incomplete metadata and older entries use focused reads. A missing profile entry is never evidence of deletion. Each batch bounds original checks to 100 and profile pagination to ten pages, with loop detection and a global 1,000-page safety bound. All native requests remain serialized with existing cooldowns.

Stop preserves completed observations; the next batch continues unchecked rows. Found candidate IDs are remembered for six hours across restarts, separately from unavailable IDs and known deletions. Reimported candidates remain unselected. History stores no body text or account identifiers, expires and is cleared with local checkpoints or disconnect. Read-only progress preserves previous write checkpoint states. Submitted or uncertain writes clear their found marker. Nothing resumes or writes automatically.

Native edit/delete preflights, fresh author/account checks, five-minute previews, explicit confirmation and independently verified combined stages remain mandatory. A completed read batch creates a new review; merely changing settings or restoring unavailable rows does not renew an expired preview.

Validation includes a 100-item/one-profile-page case with zero individual lookups, lookup fallback for an existing original absent from the profile, Stop/resume without repeated focused reads, persisted unselected candidates with expiry, clearing uncertain candidate markers, preservation of prior uncertain write states and ordinary-scan hydration. Isolated Electron HTTPS fixtures cover the import/check/select workflow without real Reddit changes. Real account timing and classic-layout compatibility remain subject to maintainer validation; the fixture speedup is not a promised Reddit throughput figure.

Windows x64 and Linux x64 only. Integrated GitHub update behavior is unchanged. GPL-3.0-only; official binaries include corresponding source ZIP and SHA256SUMS.
